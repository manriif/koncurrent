expect open override fun tryLock(): Boolean(source)

Acquires the read lock unless another thread holds the write lock. Never waits.

Return

open override fun tryLock(timeout: Duration): Boolean(source)

Acquires the lock if that is possible within timeout. Does not wait when timeout is zero or negative. Common code reaches it through the extension of the same name.

On JS and Wasm this never waits, since no other thread could release the lock.

Return

whether the lock was acquired

Throws

InterruptedException

if the thread is interrupted before or while it waits
