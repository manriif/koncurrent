Condition

@SubclassOptInRequired(markerClass = [InternalForInheritanceKoncurrentApi::class])
expect interface Condition(source)

A place where the threads that hold a lock wait for something to become true. It is created by ReentrantLock.newCondition.

A thread calls await while it holds the lock. This releases the lock and puts the thread to sleep. Another thread then takes the lock, changes the state that the first one waits for, and calls signal or signalAll. The first thread wakes up, and returns from await once it holds the lock again.

await may return while nothing was signalled. So always wait in a loop that checks the state again:

lock.withLock {
    while (queue.isEmpty()) {
        notEmpty.await()
    }

    queue.removeFirst()
}

This interface is not meant to be implemented outside of this library. On the JVM and Android it is java.util.concurrent.locks.Condition, which has more functions to implement.

Platforms

  • JS and Wasm have one thread, which nothing could wake up. await throws IllegalStateException there.

open fun await(timeout: Duration): Boolean

Waits as await does, for timeout at most. Does not wait when timeout is zero or negative. The current thread holds the lock again when this returns or throws. Common code reaches it through the extension of the same name.
