A thread, which runs code at the same time as the other threads of the program.

A thread runs its Runnable once start is called, and ends when that returns. join waits for its end. An exception that escapes the Runnable ends the thread, which prints the stack trace. Prefer thread, which creates and starts a thread from a lambda.

Interruption

interrupt asks a thread to stop what it is doing. It only sets a flag of the thread. A function of this library that waits throws InterruptedException when it finds the flag set, and clears it: sleep, join, the waits of a condition, of a semaphore and of a latch, and the ways to take a lock that say so. A thread that waits in one of them is woken up for that. Code that does not wait reads the flag itself, with isInterrupted or interrupted.

Platforms

  • On the JVM and Android this is java.lang.Thread.

  • On native this is a thread of the system, with three limits.

  • interrupt does not wake a thread up from a call to the system, like a read of a file.

  • A program ends when its main function returns, whether threads still run or not. So setDaemon changes nothing there.

  • currentThread also works on a thread that this library did not start, like the main one. Such a thread never tells that it ended. isAlive stays true, and join waits until its time is over, or forever.

  • JS and Wasm have one thread, so this class does not exist there.
