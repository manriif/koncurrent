NavigableSet

@SubclassOptInRequired(markerClass = [InternalForInheritanceKoncurrentApi::class])
expect interface NavigableSet<E : Any> : MutableSet<E> (source)

A set that keeps its elements in order, and that finds the closest ones to a given element.

The order is the natural one of the elements, or the one of a Comparator. An iterator goes through the elements from the first one to the last one.

subSet, headSet, tailSet and descendingSet return views. A view reads and changes the set that it comes from, and refuses an element that is out of its bounds.

On the JVM and Android this is java.util.NavigableSet.
