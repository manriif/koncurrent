ConcurrentNavigableMap

@SubclassOptInRequired(markerClass = [InternalForInheritanceKoncurrentApi::class])
expect interface ConcurrentNavigableMap<K : Any, V : Any> : MutableMap<K, V> (source)

A map that keeps its keys in order, that finds the closest ones to a given key, and that several threads use at once.

The order is the natural one of the keys, or the one of a Comparator. The keys, the values and the entries are gone through from the first key to the last one.

subMap, headMap, tailMap and descendingMap return views. A view reads and changes the map that it comes from, and refuses a key that is out of its bounds.

An entry that this map returns is a copy of one moment. Its setValue throws UnsupportedOperationException.

On the JVM and Android this is java.util.concurrent.ConcurrentNavigableMap.
