ThreadLocal

expect class ThreadLocal<T>(source)

A variable that holds one value for each thread. A thread only reads and writes its own value.

The value of a thread is dropped when the thread ends, and when this thread local is no longer referenced.

Platforms

  • On the JVM and Android this is java.lang.ThreadLocal.

  • On native each thread keeps its values in a table of its own.

  • JS and Wasm have one thread. This is a plain variable there.
