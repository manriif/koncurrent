CopyOnWriteArraySet

expect class CopyOnWriteArraySet<E> : MutableSet<E> (source)

A set that any number of threads can read and update at the same time, on a CopyOnWriteArrayList. Every update makes a new copy of the elements.

A read never blocks. An update costs a copy of the whole set, and finding an element costs a look at each of them. So this set suits a few elements that are read often and rarely changed, like a set of listeners. Use a ConcurrentHashSet for more.

Each update is atomic. Among the threads that add the same element at once, only one gets true.

An iterator is a snapshot. It goes through the elements as they were when it was created, in the order of their addition. It never throws ConcurrentModificationException, and it cannot change the set: its remove throws UnsupportedOperationException.

Elements can be null.

Platforms

  • On the JVM and Android this is java.util.concurrent.CopyOnWriteArraySet.

  • Elsewhere this is the same class over the list of this library.
