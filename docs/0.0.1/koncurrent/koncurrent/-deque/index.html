Deque

@SubclassOptInRequired(markerClass = [InternalForInheritanceKoncurrentApi::class])
expect interface Deque<E : Any> : Queue<E> (source)

A Queue with two ends. Elements can be added, removed and read at its head and at its tail. So it serves as a queue, where the first element in leaves first, and as a stack, where the last one in leaves first.

Each operation exists at both ends, in the two forms of a queue:

Head, throwsHead, returns a valueTail, throwsTail, returns a value
AddaddFirstofferFirstaddLastofferLast
RemoveremoveFirstpollFirstremoveLastpollLast
ReadgetFirstpeekFirstgetLastpeekLast

The functions of a queue add at the tail and take from the head: add is addLast, and poll is pollFirst. The functions of a stack work at the head: push is addFirst, and pop is removeFirst.

This interface is not meant to be implemented outside of this library. On the JVM and Android it is java.util.Deque, which has more functions to implement.
