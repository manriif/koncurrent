computeIfAbsent

@IgnorableReturnValue
actual fun <K : Any, V : Any> ConcurrentHashMap<K, V>.computeIfAbsent(key: K, mappingFunction: (K) -> V): V(source)

Returns the value of key. If the key has none, calls mappingFunction, maps the key to its result and returns it.

The whole call is atomic. Among the threads that ask for the same absent key at once, only one calls mappingFunction, and the others get its result. A key that already has a value is returned without locking.

Use it to create a costly object once per key.

mappingFunction must not update this map. If it throws, the exception is rethrown and the key keeps no value.

Return

the value that the key had, or the computed one
