BlockingDeque

@SubclassOptInRequired(markerClass = [InternalForInheritanceKoncurrentApi::class])
expect interface BlockingDeque<E : Any> : BlockingQueue<E> , Deque<E> (source)

A Deque whose threads can wait at both ends: for room when they add to a full deque, and for an element when they take from an empty one.

It is a BlockingQueue too. put is putLast, and take is takeFirst.

Head, waitsHead, for some timeTail, waitsTail, for some time

RemovetakeFirstpollFirst with a limittakeLastpollLast with a limit

This interface is not meant to be implemented outside of this library. On the JVM and Android it is java.util.concurrent.BlockingDeque, which has more functions to implement.

Platforms

  • JS and Wasm have one thread, which nothing could wake up. A put on a full deque and a take on an empty one throw IllegalStateException there.
