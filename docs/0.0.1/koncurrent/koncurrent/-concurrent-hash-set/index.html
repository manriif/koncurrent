ConcurrentHashSet

class ConcurrentHashSet<E : Any> : MutableSet<E> (source)

A hash set that any number of threads can read and update at the same time. It is backed by a ConcurrentHashMap and behaves as its keys do.

contains never blocks. add and remove are atomic. The bulk functions are not. size and isEmpty give a transient state while other threads update the set.

Its iterators are weakly consistent. They never throw ConcurrentModificationException. They visit once each element that existed when they were created, and may or may not reflect later updates.

Elements cannot be null.
